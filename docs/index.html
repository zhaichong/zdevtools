安全与脱敏

工业级隐私合规

所有抓取的调试会话数据全部存储在本地。在导出和展示前，系统会自动匹配规则对用户的 API Token、Cookies、敏感 Key 以及 Headers 执行实时脱敏过滤，守护企业隐私红线。

会话视频化

rrweb 录屏回放

通过 CDP 无感挂载 DOM 闪变录像引擎。无需手机摄像机对准屏幕，便可自动记录页面上所有的微小渲染细节，并支持在诊断报告中像视频一样进行回放。

数据取证

全维堆栈日志聚合

在用户复现异常的瞬间，系统会自动搜集并归档所有的 HTTP 网络调用状态、Console 日志堆栈。内置排查器自动结合多维度异常指标，提取前 3 个最可能的致命原因。

极致简单的工作流。

无需复杂的说明书，简单三步即可将案发现场以诊断报告形式流转至开发团队。

1

发现并点击“开始诊断”

通过 USB 连入后，系统会自动显示可调试的 WebView。点击“开始诊断”一键架设本地取证代理。

2

复现异常并静默录制

在手机上滑动操作。探针在内存中以零侵入、零开销的方式记录页面 DOM、网络和报错日志。

3

导出本地诊断包

点击“生成报告”，一键导出经过脱敏的便携诊断压缩包，可直接发送给开发人员在本地进行会话复现。
