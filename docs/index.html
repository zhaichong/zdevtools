核心功能特性

专为工业级现场排查设计，解决传统在线调试工具对网络和调试线的强依赖痛点。

智能目标发现

自动识别 USB 连入或局域网内的 Android 设备，支持多通道（ADB & HDC）自动发现可调试的 WebView 页面，彻底告别繁琐的命令行端口映射。

深度调试取证

通过 CDP（Chrome DevTools Protocol）无感注入内存探针，一站式收集运行时的 HTTP 错误、Console 异常日志，并自动聚合提取可能的原因。

会话沙盒回放

内置轻量级录屏分片引擎，在完全离线状态下录制页面 DOM 变化。诊断报告中附带完整的用户操作还原与录屏回放，无需现场视频录像。

本地数据脱敏

针对企业安全合规要求设计，诊断报告全部保存在本地（UserData 目录）。导出前会自动对 Token、Cookies、敏感 Key 以及请求 Headers 执行脱敏过滤。

极其简单的诊断流程

无论处于断网的工厂车间还是封闭的机房内网，您都可以在 1 分钟内完成一次 WebView 的完整取证。

自动检测与连接设备

使用数据线连接手机，开启手机的 “USB 调试”。ztools 的双驱动引擎（支持 ADB 与 HDC 通道）会立即开始后台检索，并自动在面板中显示可连接设备和可调试的 WebView 进程，点击“开始诊断”即可建立长连接。

  • 免除手动输入 adb forward / chrome://inspect 繁琐命令
  • 自动提取当前运行 WebView 容器的内核版本与标题
  • 支持离线/内网 ADB 驱动自动适配

内存探针无感录制

系统会自动在 WebView 页面内存中挂载临时的诊断探针。当您在手机上操作应用复现 Bug 时，所有的 DOM 闪变、接口返回状态、脚本致命错误将被探针静默打包写入本地临时缓存，不会在业务项目中留存任何文件。

  • 探针仅存在于临时内存，刷新页面或拔出手机自动释放
  • 采用高效分片压缩，几乎不占用手机端系统资源
  • 支持捕获网络状态、HTTP 状态码及 Response 主体
