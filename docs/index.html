FEATURES

不仅是调试，更是完整的取证闭环

解决调试线依赖，解决代理阻断，满足企业合规，把一切都留在本地。

智能免配目标发现

自动识别通过 USB 接入的 Android/HarmonyOS 设备，在局域网下多通道（ADB & HDC）自动发现可调试的 WebView 实例，免除命令行端口绑定与复杂的配置。

全维证据深度探查

利用 CDP 协议，直接向 WebView 注入纯内存诊断探针。在复现过程中自动截获 HTTP 请求体、Response Header、Console 日志堆栈并标记疑似根因。

操作会话视频复现

基于底层的 DOM 录制分片引擎，完全在本地对操作页面进行高精度序列化。生成的诊断会话报告支持沙盒级视频回放，彻底代替模糊不清的手机录像。

工业安全数据脱敏

诊断报告本地化持久存储（存至 UserData 目录而非云端）。在导出或展示时，会自动根据掩码库对 Token、Cookie、敏感 Header 及密码执行脱敏遮掩。

DIAGNOSTIC PROCESS

一分钟极速诊断流

无论在完全封闭的开发机房，还是网络断绝的工业现场，只需几步即可导出完美的根因文件。

双核扫描免配连接

将手机连入电脑并启用 USB 调试。ztools 的后台驱动会自动开始毫秒级轮询：

  • 免打字：无需配置 ADB Port Forward 等环境参数。
  • 智能读取：自动拉取 WebView 的内核版本与当前进程标题。
  • 双模兼容：同时支持传统 Android 调试通道与鸿蒙 HDC 调试通道。

离线容器专属工作台

点击实例后，ztools 将在本地快速生成专属调试台，彻底剥离外网依赖：

  • 本地载入：内置精简离线版 DevTools 前端镜像，无需下载。
  • 代理加速：后台自动架起 WebSocket 映射，绕过网络拦截。
  • 界面集成：将控制台、接口捕获和回放面板有机融为一体。

内存探针无感捕获

探针运行于页面沙箱内存中，在用户复现时无损搜集全部报错数据：

  • 零污染：探针不污染网页代码结构，退出或刷新即刻释放。
  • 全面追踪：同时追踪网络异常（500/404）、JS 异常与 DOM 变化。
  • 高效分片：把捕获的所有 rrweb 快照在本地进行压缩分片储存。

脱敏报告一键分发

复现完成后一键归档，导出便携式的排查压缩包：

  • 自动脱敏：过滤 Authorization 头、密码及 Cookies。
