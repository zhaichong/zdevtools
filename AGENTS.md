# AGENTS.md

## Design Standard

- UI changes must be designed for the packaged Electron app first, not the Vite web preview. Before implementing a visible redesign, provide a confirmable design draft when the user asks for one. Product tool pages should show only key task information, use clean aligned panels, clear states, visible controls, and must fix usability/function bugs together with visual polish. Do not duplicate Chrome DevTools features already embedded in the app.
